# 使用说明

[English](user-guide.en.md) · [安装](../README.md)

@Andrei_9527 把 X 放进 Chrome 侧栏，并在本机整理关注和粉丝。需要 **Chrome 145+**，以及能打开 [x.com](https://x.com) 的网络。安装步骤见 [README](../README.md)。

本工具与 X 官方无关。重要账号请阅读文末的风险提示。

## 打开侧栏

先在普通页签登录 [x.com](https://x.com)。然后任选一种方式打开侧栏：

- 点击 Chrome 工具栏的扩展图标，选择 **@Andrei_9527**
- 按 `Alt+Shift+X`

侧栏可以拖宽或拖窄。时间线没有出来时，先看普通页签里的 x.com 是否已登录、网络是否正常，再点击侧栏里的 **首页**。

## 顶栏

从左到右是：

| 控件 | 作用 |
| --- | --- |
| 首页 | 打开 X 的首页时间线 |
| 粉丝管理 | 打开本机的关注与粉丝页面。这一页不显示缩放 |
| − / 百分比 / + | 缩放时间线，范围 50% 到 150%，每次 10%。再打开侧栏时保留上次的比例 |
| 语言 | 使用与 X 相同的语言列表 |
| 太阳 / 月亮开关 | 日间在左，夜间在右。圆点滑到哪一侧，哪一侧的图标就压在白点上 |

打开侧栏时，扩展按浏览器语言设置 X 的界面语言。已经登录时，这会改掉该 X 账号的显示语言，其他设备上的 X 也会跟着变。之后在菜单里另选的语言会被记住，下次打开仍用这个选择。

侧栏自己的文字有简体中文、繁体中文和英文。选了这三种以外的语言时，X 换成该语言，侧栏文字用英文。

日间和夜间选择会保留。切换时，侧栏和里面的 X 一起换主题。

## 粉丝管理

点击 **粉丝管理**。页面标题是「关注与粉丝」，下面有三个名单：

| 名单 | 内容 |
| --- | --- |
| 未回关 | 你关注了对方，最近一次成功同步里对方没有关注你 |
| 取关 | 曾经出现在粉丝名单里，后来的完整同步里不再出现 |
| 已忽略 | 你手动隐藏的人 |

每一行是同步时读到的昵称和 `@用户名`。没有昵称时只显示 `@用户名`。点击名字会在新页签打开这个人的 X 主页。

### 立即同步

登录后点击 **立即同步**。侧栏会在后台滚动你的粉丝页和关注页，在这台电脑上比较名单。同步使用当前的 X 网页登录，不使用开发者 API 额度，也不会另开一个给你看的页签。同步过程中请保持侧栏打开。

同一个 X 账号两次同步至少间隔 **1 小时**：

- 只有粉丝和关注都读完并保存成功才开始计时。读取失败、名单不完整，都不进入这一小时
- 按钮改成「60 分钟后」这样的剩余时间，并保持禁用
- 关掉侧栏再打开，剩余时间还在
- 还没登录就点同步，只会提示先登录，不会开始这一小时

还没有同步过的账号可以马上同步。已经有记录的账号，从最近一次同步起算满一小时才能再同步。

同步时，扩展会看 X 名单请求还剩多少额度。剩余两次或更少时，暂停滚动，等到 X 给出的重置时间再继续当前这份名单。

粉丝只加载了一部分时，这次会保存已经读到的人，但不会据此判断新的取关。等一次完整同步后，才会更新取关名单。

### 天数、忽略和每日记录

**未回关至少 N 天**只作用于「未回关」。天数从第一次同步发现对方未回关的那天起算，算到最近一次成功同步。中间发现对方已经回关，之后又变成未回关，天数重新起算。日期按北京时间。

点某一行的 **忽略**，这个人会同时从「未回关」和「取关」里消失，并出现在 **已忽略**。再点 **取消忽略** 可以恢复。忽略名单按当前 X 账号存在本机。

**每日记录（北京时间）**保存每次同步读到的关注数、粉丝数和未回关数。同一天再同步，会更新这一天的数字。

### 取关怎么判断

取关按 X 的用户 ID 比较，改名之后仍能对上。第一次网页同步只建立基线，不把当时不在粉丝里的人全部算成新取关。对方后来重新关注你，会从取关名单移出。人数只统计这次实际读到的用户。

## 数据存在哪里

粉丝快照、未回关、取关、已忽略和每日人数都按 X 账号存在这台电脑的 Chrome 里。扩展不会把这些名单上传到自己的服务器。换一个 X 账号登录后，看到的是那个账号自己的记录。
